# 로또 번호 예측기

과거 당첨 데이터를 분석해 로또 번호 조합을 만들어 주는 웹앱입니다.
통계 시각화와 추첨기 애니메이션을 함께 제공합니다.

## 바로 실행하기 (설치 불필요)

저장소의 **`standalone.html`** 파일 하나만 내려받아 더블클릭하면 브라우저에서 바로 열립니다.
Node.js도, 서버도 필요 없습니다.

## 개발 환경에서 실행

```bash
npm install
npm run dev          # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | `dist/` 로 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run build:standalone` | 빌드 후 `standalone.html` 재생성 |
| `node scripts/update-draws.mjs` | 동행복권에서 최신 회차를 받아 데이터 갱신 |

## 배포 전 체크리스트

1. `index.html`, `public/robots.txt`, `public/sitemap.xml` 의 `example.com` 을 실제 도메인으로 교체
2. `og.png`(1200×630) 제작해 `public/` 에 배치
3. `.env.example` 을 `.env` 로 복사하고 애드센스 ID 입력 (선택)
4. `node scripts/update-draws.mjs` 로 회차 데이터 최신화

유입·수익화 계획은 **[MARKETING.md](./MARKETING.md)** 참고.

## 화면 구성

### 예측
- **생성 전략 5종** — AI 종합 / 핫 넘버 / 콜드 넘버 / 균형 조합 / 완전 랜덤
- 한 번에 1·3·5·10 조합 생성 (조합끼리 중복되지 않음)
- 원하지 않는 번호를 눌러서 **제외**
- 조합마다 합계·홀짝·구간 분포·연번 개수와 **균형도** 표시
- 파란 링은 그 조합에서 모델 점수가 가장 높은 번호

### 추첨기
- 공 45개가 든 추첨기를 캔버스 물리 시뮬레이션으로 구현
- 송풍구 바람·중력·공끼리 충돌·벽 반사를 계산해 공이 순환
- 뽑힌 공은 추첨기에서 빠지므로 번호가 겹치지 않음
- AI 가중치 적용 여부를 켜고 끌 수 있음

### 통계
- 45개 번호 **히트맵** (전체 출현 빈도 + 핫/콜드 표시)
- 많이 나온 번호 / 오래 안 나온 번호 순위
- 구간별 출현, 홀짝 비율, 당첨 번호 합계 분포
- 자주 함께 나온 번호 짝, 최근 당첨 번호

### 보관함
- 마음에 드는 조합을 브라우저에 저장 (localStorage)
- 저장한 조합을 **과거 회차와 대조**해 몇 등이었을지 표시

## 예측 모델

번호마다 아래 4가지 지표를 0~1로 정규화해 가중 합산합니다.

| 지표 | 가중치 | 내용 |
| --- | --- | --- |
| 출현 빈도 | 30% | 전체 기간 동안 나온 횟수 |
| 최근 흐름 | 35% | 최근 20회 안에서의 출현 |
| 미출현 기간 | 20% | 마지막 출현 이후 지난 회차 수 |
| 동반 출현 | 15% | 다른 번호와 같이 나온 정도 |

`균형 조합` 전략은 여기에 더해 합계·홀짝·구간 분포·연번 개수가 과거 평균에
가까운 후보를 고릅니다.

## 데이터

`src/data/lottoData.js` 에 회차별 당첨 번호가 한 줄씩 들어 있습니다.

```
회차 번호1, 번호2, 번호3, 번호4, 번호5, 번호6 보너스
1201 7, 9, 24, 27, 35, 36 37
```

현재 40회분(1162–1201회)이 들어 있습니다. 줄을 추가하면 그대로 반영됩니다.
회차 수가 적으면 통계의 표본이 작다는 점은 감안해 주세요.

## 참고

로또 추첨은 매 회차가 독립적인 확률 게임입니다. 과거 데이터로 다음 회차를 맞힐 수
없으며, 이 앱의 **균형도는 당첨 확률이 아니라** 조합의 구조가 과거 당첨 조합과
얼마나 비슷한지를 나타내는 참고 수치입니다. 재미로만 사용해 주세요.
